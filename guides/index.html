Best place to start

If you are brand new to solar, start with Solar Power System Basics so panels, batteries, charge controllers, inverters, and system voltage make sense before you compare gear.

If you already know your monthly electric bill, start with the Solar Kit Size Calculator. If you are planning a cabin, RV, shed, tiny home, backup setup, or off-grid system, start with the Off-Grid Solar Calculator.

Not sure yet? Use the homepage calculator first, then come back to these guides once you know whether you are shopping for more panels, more battery, a larger inverter, a portable power station, or a different type of system.

How this funnel works

1. Use the calculator to get a realistic starting range for solar watts, battery size, inverter output, and system type.

2. Use the guides to understand what those numbers mean, what tradeoffs matter, and what kind of setup fits your use case.

3. Move into the equipment pages and reviews once you know what class of gear you should actually be comparing.
