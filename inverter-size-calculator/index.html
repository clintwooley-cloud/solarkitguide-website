Basic inverter rule

Start with the largest loads that may run at the same time, then add headroom. For surge-heavy equipment, check locked-rotor amps or manufacturer startup requirements.

12V, 24V, or 48V?

Small portable/RV systems often use 12V. Medium systems often use 24V. Larger off-grid and home backup systems usually make more sense at 48V because current is lower and wiring is more manageable.
