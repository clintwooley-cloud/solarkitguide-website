Solar Kit Size Calculator

The fastest way to avoid buying the wrong solar kit is to estimate your actual energy target first, then match panels, batteries, and inverter size to that target.

Use the calculator

What this calculator estimates

  • Daily energy use in watt-hours or kWh
  • Recommended solar panel array size
  • Battery capacity for backup or off-grid use
  • Inverter size and system voltage category
  • Equipment categories to compare before buying

For home solar, start with your electric bill. For cabins, RVs, sheds, or off-grid systems, start with the appliances you want to run.

Rule of thumb

Solar array watts are roughly daily watt-hours divided by peak sun hours, then adjusted upward for losses. Battery capacity depends on how long you want to run without sun and how deeply the battery can safely discharge.
