## Sizing guidance to include

Use rough math, not promises:

- 1,024Wh station: about 820–900 usable Wh after inverter losses if using AC loads.
- 1,152Wh station: about 920–1,000 usable Wh after inverter losses.
- 2,073Wh station: about 1,650–1,850 usable Wh after inverter losses.

Examples:
- 50W portable fridge: 1kWh class may run roughly 16–20 hours if constantly drawing 50W, longer if cycling.
- 85W TV: 1kWh class roughly 10–11 hours after losses.
- 600W microwave: 1kWh class can run it briefly, but not for long; high-watt appliances drain batteries fast.
- 1,500W heater/hair dryer: output may handle it, but runtime is short. Explain the difference between watts and watt-hours.
